# Director script playbook

VideoCraft generates three structurally different approaches, then runs a separate critic pass before showing a script. The critic scores hook, clarity, factual grounding, specificity, spoken rhythm, visual potential, emotional honesty, and brief fit. A deterministic quality gate rejects common AI filler before the result reaches the creator.

The creator can save a standing style note. Sentence length is learned locally from their script edits and supplied to later planning requests. Preference data remains editable and is not used to train a shared model.

## Open craft references

The implementation is original, concise operational guidance informed by these openly licensed skill libraries:

- `jtydhr88/screenwriting-skills` — MIT; screenwriting, television writing, dramaturgy.
- `smixs/visual-skills` — CC BY 4.0; concrete visual dramaturgy and filmable prompting.
- `zenstory-ai/drama-skills` — MIT; staged script-to-storyboard workflow and review gates.
- `DenisHumen/cinema-skills` — MIT; pipeline and style-bible architecture.

No course text, book excerpt, screenplay, or proprietary example is embedded in VideoCraft. Keep licence and attribution records when adding future references.
