# VideoCraft

VideoCraft is an AI-assisted video editor designed to turn raw media and a creator's intent into explainable, reviewable editing suggestions and reproducible renders.

This repository contains the architecture foundation, not a finished editor. It establishes a versioned domain model, explicit provider ports, reusable strategy boundaries, a feedback loop for evaluation, and clear application, worker, API, web, and infrastructure seams.

See ARCHITECTURE.md and docs/roadmap.md for the current boundary and plan.
